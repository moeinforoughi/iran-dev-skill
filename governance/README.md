# Project governance and long-term context

This directory is the compact operating manual for maintainers and future AI agents. It records why the project exists, how its files fit together, what has already been built, what should come next, and how to extend it without wasting tokens or making unsafe guesses.

## Read by task type

| Task | Read |
|---|---|
| Any code/docs change | `../AGENTS.md`, `CONTRIBUTING.md`, relevant part of `TASKS.md` |
| New feature or scope debate | `PROJECT_CHARTER.fa.md`, `ARCHITECTURE.md` |
| Prompt, token, or diagnostic changes | `TOKEN_EFFICIENCY.md` |
| Mirror/source/tool catalog change | `CONTRIBUTING.md` and `../references/source-policy.md`; then only the relevant catalog |
| Release or behavior change | `CHANGELOG.md`, validation steps in `CONTRIBUTING.md` |
| Understand prior work | `WORK_LOG.md` |

Do not load every file just because it exists. Follow the smallest relevant reading path.
